# 项目专用开发指南

本目录用于保存当前项目自己的真实约定。模板只提供占位结构；迁移到新项目后，应按项目实际技术栈和业务边界补充。

## 读取顺序

1. `directory-structure.md`
2. `error-handling.md`
3. `logging-guidelines.md`
4. `android-browser-contracts.md`
5. `download-queue.md`（涉及下载任务、队列、通知、日志、历史去重时必读）
6. `quality-guidelines.md`
7. `data-migration.md`（涉及 applicationId、目录改名、导入导出或用户数据迁移时必读）

## 写入原则

- 记录项目实际约定，不写空泛愿望。
- 优先放可执行规则：目录边界、命名、错误处理、测试要求、禁用模式。
- 引用代码示例时使用当前项目真实文件。
- 如果当前项目不是后端/前端项目，也保留本目录作为项目通用规则层，必要时新增更贴合项目类型的规则文件。
- 浏览器壳、WebView、标签页、检测浮窗、首页或广告拦截相关任务，必须额外读取 `android-browser-contracts.md`。
- 涉及应用身份切换、数据导出/导入、下载目录迁移或跨版本兼容时，必须额外读取 `data-migration.md`。

## 修改前检查

- 本次任务触及哪些目录、模块或包。
- 是否已有同类实现可以复用。
- 是否改变既有行为、数据格式、接口契约、部署方式或复现路径。
- 需要运行哪些最低限度的校验。
