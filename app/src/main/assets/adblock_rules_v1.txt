# SurfSave network ad-filter rules v1
# UTF-8 format: action|kind|value|page-domain[,page-domain]|flags
# Supported actions: block, allow
# Supported kinds: domain, path, page (page is allow-only)
# Supported flags: third-party, soft, request-domain=<domain>
#
# Site-specific rules remain data, not WebView branches. Example syntax:
# block|domain|ads.cdn.example|example.com|third-party
# block|path|/vast/||request-domain=ads.cdn.example
# block|path|/possible-ad/||third-party,soft
# allow|path|/required-player-bootstrap/|example.com|
# allow|page|example.com||
